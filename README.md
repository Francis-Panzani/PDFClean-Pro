# PDFClean Pro

PDFClean Pro est un logiciel professionnel permettant de supprimer automatiquement les éléments répétitifs d'un document PDF.

Fonctionnalités :

- Détection automatique des en-têtes
- Détection automatique des pieds de page
- Détection des numéros de page
- Détection des filigranes
- Rapport HTML
- Validation
- Interface graphique

## Installation

```bash
pip install -e .
```

## Utilisation

```bash
pdfclean document.pdf
```
